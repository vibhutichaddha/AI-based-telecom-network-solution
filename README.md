# AI-Based 5G KPI Anomaly Detection Dashboard
## Overview
This project is a capstone solution that implements an AI-powered dashboard that monitors 5G telecom network Key Performance Indicators (KPIs) and automatically detects anomalous network behavior using the Isolation Forest algorithm.
The application preprocesses telecom KPI data, performs feature engineering, setects anomalies using machine learning, and visualizes network health through an interactive Streamlit dashboard.
## Features
- Telecom KPI data preprocessing 
- Data validation and cleaning
- Feature engineering
- Isoaltion Forest-based anomaly detection
- Hyperparameter tuning
- KPI trend visualization
- Cell health monitoring
- Interactive Streamlit dashboard
- Saved trained model
- Modular project structure
- GitHub version control

## Dataset Description
The project uses a telecom KPI dataset containing performance metrics collected from 5G cell towers
### Dataset Columns
- Cell_ID
- Timestamp
- RSRP
- SINR
- Latency
- Throughput
- Packet_Loss
- Connected_Users
- Signal_Quality_Score
- Network_Load
- Network_Health_Index
The processed dataset also containa the predicted anomaly label generated by the Isolation Forest model.
